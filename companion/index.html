Saved data & installation

Save your PC reference copy

While connected to the PC QR session, choose its offline copy export. Save that file on your phone, then open this installed app and import it here.

The copy contains the selected guild and the current zone and quest details. It is a dated reference; refreshing public catalogs does not update guild records.

Nothing is uploaded. You will review the copy before replacing saved data.

iPhone or iPad

  1. Open the permanent vantageupdates.github.io/vantage/companion/ address in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Enable Open as Web App, then tap Add.
  4. Open the new icon while online and wait for the sections you need to say Ready offline.
  5. Import your guild copy inside the installed app. Safari and the Home Screen app can keep separate data.

Android or desktop Chrome

  1. Tap Install App above.
  2. If unavailable, use the browser menu → Install app or Add to Home screen.
  3. Open the installed app online once, check Ready offline, then import your saved copy there.

What remains available

  • Offline after saving: full Market and Spell search; zone names and quest titles; imported guild records and imported zone/quest details.
  • Needs internet: refreshing PigParse prices and opening Project 1999 Wiki pages.
  • Needs the PC QR session: live timers, buffs, controls and EverQuest Live. Open the private QR link with the PC running on the same Wi-Fi. Live images are never saved here.

If your old icon opens a local PC address, replace it with this permanent HTTPS icon once. Keep the private PC QR link for live tools.

Saved copies stay on this device. Browser data clearing or device storage cleanup can remove them; keep an exported backup. No OpenDKP password or PC connection key is imported.
