# Vantage

Vantage is a portable Windows companion for EverQuest Project 1999.

Download the current single-file build from [Releases](https://github.com/vantageupdates/vantage/releases/latest). No installer or files beside `Vantage.exe` are required.

## Updates

Vantage checks this repository's stable GitHub Releases. Downloads are staged temporarily, verified against GitHub's SHA-256 digest, installed beside the existing executable, and then removed.

## Data and safety

Vantage reads EverQuest log files and provides local overlays, timers, maps, combat analysis, spell tools, and market references. It does not automate gameplay or send input to EverQuest.
